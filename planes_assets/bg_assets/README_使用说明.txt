B737-800 Blue Sky 涂装资产

1. 推荐直接使用：B737_800_BlueSky.glb
   已内嵌 Base Color、Normal、Metallic-Roughness 三张 4096×4096 PBR 贴图。

2. 若在 Three.js / WebGL 中替换原模型贴图：
   将 B737_800_BlueSky_BaseColor_4096.png 设置为原材质的 map（颜色贴图）。
   normal_1.png 与 metallicRoughness_1.png 沿用原模型，无需修改。

3. 已保护区域：
   驾驶舱挡风玻璃、客舱舷窗、舱门细节、发动机进气口、轮胎、通风口和主要深色结构细节。

4. 颜色空间：
   Base Color 使用 sRGB；Normal 与 Metallic-Roughness 使用 Linear / NoColorSpace。
