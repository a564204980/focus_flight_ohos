# Antigravity 常用 Slash 指令中文速查与实践指南

Slash 指令（以 `/` 开头的快捷指令）是 Antigravity 专为用户和 Agent 之间快速对齐交互模式、触发高级编排行为而设计的功能。

---

## 核心指令中英对照一览表

| 指令 | 中文名称 | 适用场景 | Agent 行为特征 |
| :--- | :--- | :--- | :--- |
| `/goal` | **长跑攻坚模式** | 跨模块大型重构、通宵长任务、多步骤复杂攻坚 | Agent 自动开启高度自主推进模式，坚持不懈直到完全达成最终目标，绝不半途而废。 |
| `/boost` | **深度思辨与多视角规划** | 复杂架构设计、关键性能重构、风险极高的系统变动 | Agent 自动调用深度规划能力，从多角度审视技术方案、潜在隐患与回滚方案。 |
| `/grill-me` | **交互式方案对齐面试** | 需求模糊、存在多种可选实现路径、需要决策取舍 | Agent 会像技术面试官一样，对用户进行连环提问，深挖设计意图并逐项敲定细节。 |
| `/schedule` | **定时提醒与后台周期任务** | 定时提醒检查、后台编译/部署巡检、周期性心跳探测 | 快速创建一次性单触发倒计时或基于 Cron 表达式的周期性后台调度任务。 |
| `/browser` | **浏览器自动化与视觉验证** | 网页操作、UI 视觉验收、网页抓取与动态内容交互 | 调起无头或可视浏览器引擎，自动浏览、截屏、点击并返回页面内容。 |
| `/learn` | **经验沉淀与行为固化** | 用户纠正了 Agent 的某项不良习惯或提供了独有解决方案 | 将本次对话沉淀的教训、规范或解决方案固化为项目级/全局级规则（Rules）。 |
| `/teamwork-preview` | **多智能体协同开发** | 超大体量工程、多领域并行开发 | 启动多个专业子智能体（Subagents）并行分工协同推进。 |

---

## 推荐话术与场景示例

当用户遇到以下场景时，Agent 应主动向用户推荐对应的中文 Slash 指令：

1. **用户提出复杂模糊的需求**：
   > 💡 *“当前需求涉及多个技术方案的选型，您可以输入 `/grill-me` 与我开启交互式方案对齐面试，我们一起逐一敲定关键设计细节。”*

2. **用户希望执行耗时极长、需要坚决攻克的任务**：
   > 💡 *“这项重构涉及多个核心模块，您可以输入 `/goal` 开启长跑攻坚模式，我将进行全自动深度推进直到彻底完成。”*

3. **用户希望在后台监控或定时触发**：
   > 💡 *“您可以输入 `/schedule` 来设定一个定时器或周期任务，我将在指定时间或每隔固定周期自动为您汇报进度。”*
