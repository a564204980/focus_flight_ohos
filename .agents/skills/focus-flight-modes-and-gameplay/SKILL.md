# Focus Flight 专注飞行模式与游戏化机制规划

本文档作为 Focus Flight 后续专注机制研发与演进的基准技术与产品规范。

---

## 一、 双专注模式产品定义（轻度 vs 严格）

### 1. 标准飞行模式（轻度 / Standard Flight Mode）
- **适用场景**: 日常轻度工作、多任务协同（需要偶尔查阅资料、回复消息等）。
- **运行逻辑**:
  - **允许后台挂机**: 用户切出应用或锁屏时，专注倒计时与飞行里程在后台持续推进；
  - **时间戳恢复机制**: 重新切回应用时，根据挂机期间的物理时间差（`Date.now() - backgroundStartTime`）平滑补齐航程与彩虹光带；
  - **无惩罚**: 随时可切出或查看其他软件，飞行不会中断或失败。

---

### 2. 深度巡航模式（严格 / Deep Cruise Mode）
- **适用场景**: 高强度沉浸式学习、备考、不被打扰的深度工作（Deep Work）。
- **核心机制 —— “离开即迫降”**:
  - **生命周期检测**: 监听应用切入后台（`onBackground` / `onPageHide`）；
  - **10 秒紧急返航宽限期**:
    - 用户一旦切离 Focus Flight，系统立即记录离屏时间戳 `leaveTimestamp = Date.now()`；
    - 系统可触发短促警示震动或发送高优先级本地通知提示：*“⚠️ 飞机偏离航线！请在 10 秒内返回座舱，否则将迫降失败”*；
  - **判定规则**:
    - **10 秒内返回**: 解除警报，恢复正常巡航，专注继续；
    - **超过 10 秒未返回**: 立即判定**专注失败**。触发迫降结算（记录迫降地点、航程作废、无法获得机长勋章）。

## 二、 鸿蒙系统端技术实现架构

### 1. 防挂起的时间戳判定机制（First Principles）
在鸿蒙系统（HarmonyOS）中，后台定时器可能会被系统能效调度挂起（Throttled/Frozen），因此**严禁仅依赖 `setInterval` 倒计时**，必须采用**基于绝对物理时间戳的差值校验**：

```ts
// 伪代码架构示范
export class FocusModeManager {
  private static leaveTimestamp: number = 0;
  private static readonly GRACE_PERIOD_MS: number = 10 * 1000; // 10秒宽限期

  /** 切入后台时触发 */
  public static onAppBackground(isDeepCruiseMode: boolean): void {
    if (!isDeepCruiseMode) {
      return; // 标准模式不受影响
    }
    this.leaveTimestamp = Date.now();
  }

  /** 切回前台时触发 */
  public static onAppForeground(isDeepCruiseMode: boolean, onFailedCallback: () => void): void {
    if (!isDeepCruiseMode || this.leaveTimestamp === 0) {
      return;
    }
    const elapsed = Date.now() - this.leaveTimestamp;
    this.leaveTimestamp = 0;

    if (elapsed > this.GRACE_PERIOD_MS) {
      // 超过 10 秒，触发迫降失败
      onFailedCallback();
    }
  }
}
```

### 2. 屏幕常亮与沉浸态支持
在开启深度巡航模式时，自动调用系统窗口 API 开启屏幕常亮：
- `windowClass.setWindowKeepScreenOn(true)`
- 在结束专注或迫降时恢复 `windowClass.setWindowKeepScreenOn(false)`。

1. **起飞前模式选择**:

   - 飞机平滑降落在当前坐标地貌上，伴随温柔解压的警示文案（如 *“航线中断，飞机已就近安全备降。休息片刻，准备下次启航吧！”*）；
   - 保持温馨可爱的产品调性，避免给用户带来负罪感或挫败感。

## 四、 突发气象与航路事件系统规划（Weather & Route Events System）

在专注飞行过程中引入随机或地域性突发气象事件，以“**沉浸陪伴、正向激励、绝不打扰用户**”为最高准则。

### 1. 氛围向（Atmosphere & White Noise）
- **🌧️ 积雨云与高空骤雨**:
  - **视效**: 地图/座舱上方平滑叠加半透明细密雨丝动效，光线微微柔和收暗；
  - **听效**: 自动平滑淡入高品质**高空细雨白噪音（Rain White Noise）**，营造深度心流空间。
- **🌬️ 平流层清风与云雾穿梭**:
  - **视效**: 飞机穿过轻盈云团，云雾在机翼两侧散开；
  - **听效**: 舒缓的高空气流白噪音，减压放松。
- **🌌 极光与夜航星轨（夜间专注专属）**:
  - **视效**: 夜间航段（20:00后）穿过极光气流，机尾彩虹光带泛起柔美波光粒子。

### 2. 玩法向（Gameplay & Gamification Rewards）
- **💨 高空顺风急流（Jet Stream Boost）**:
  - **机制**: 航途中偶遇顺风气流，尾迹光带微亮加速；
  - **收益**: 本轮专注顺利完成后，**额外获得 +10% ~ +15% 飞行里程奖励**。
- **📖 航线气象日志（Captain's Flight Log）**:
  - 专注完成后生成的专属登机牌/飞行报告中，精确记录本趟航程的气象足迹（如：*“航途遭遇【高原云雾】与【顺风急流】，机长保持极高专注度，安全平稳降落”*）。
- **🏅 专属气象成就勋章（Badges & Achievements）**:
  - 解锁【穿越风暴者】、【顺风骑士】、【极光漫游者】、【云端漫步】等稀有气象成就勋章与航线图鉴。

### 3. 客舱向（Cabin Immersion & Passenger Interaction）
- **🐱 小猫机长/乘务长暖心广播**:
  - 在客舱透视模式下，浮现可爱温馨的气泡广播：
    - *“叮咚～前方正在穿过秦岭颠簸气流，请各位乘客系好专注安全带，乘务组正在为大家递送热可可 ☕”*
    - *“报告机长，窗外出现美丽晚霞，祝您专注愉快 🌅”*
- **🪟 舷窗天气微动效**:
  - 客舱透视模式下，飞机舷窗玻璃上实时呈现**水滴滑落、水雾弥漫或微结霜花**的轻量化细腻动效。

### 4. 技术实现与架构规范
- **无打扰原则**: 气象事件与广播均为全自动环境音画表现，**严禁弹出需要用户点击的阻塞式窗口**。
- **音频平滑渐变**: 使用鸿蒙 `@ohos.multimedia.audio` 实现白噪音音量 2~3 秒平滑淡入淡出（Cross-fade），避免突兀吓到用户。
- **低功耗渲染**: 雨丝与舷窗粒子动效采用纯轻量 Canvas 或预渲染动画帧，确保后台常亮低发热、低耗电。

## 五、 正向计时与正向即时反馈系统（Count-Up Focus & Positive Immediate Feedback）

### 1. 正向计时（Count-Up / 自由探索航线）
- **核心理念**:
  - 针对需要深度心流（Flow State）、不希望被倒数闹钟强行打断的用户（如编程、写作、画画、深度阅读）；
  - 区别于传统倒计时的“时间消耗感”，正向计时提供**“时间资产累积感”**（从 $00:00$ 向上持续增长）。
- **计时机制**:
  - 起飞时不设硬性倒计时上限，时间从 `00:00:00` 开始持续向上累加；
  - 任何时候用户主动点击“降落”均视为**“圆满完成自由探索航程”**（而非提前中断或失败）。

### 2. 正向即时反馈机制（Positive Immediate Feedback）
游戏化正向即时反馈系统旨在通过高频、轻量且不打扰的多巴胺激励，增强用户的持续专注动力：

- **✈️ 航程里程实时平滑滚动（Realtime Mileage Counter）**:
  - 随着正向计时推进，界面实时计算并平滑滚动展示当前已飞行航程（例如 $1\text{秒} \approx 0.25\text{KM}$ 巡航里程）；
  - 带来即时可见的“每专注一秒都在积累实际资产”的正向心理回馈。
- **🌤️ 平流层巡航里程碑广播（Milestone Whisper Broadcasts）**:
  - 达到关键时间节点时，系统自动在座舱/舷窗左下角触发轻量化单行广播：
    - **15 分钟**: *“✈️ 飞机已平稳爬升至 10,800M 平流层巡航高度”*
    - **30 分钟**: *“☁️ 进入深度心流云海，航程已累积突破 450 KM”*
    - **60 分钟**: *“🏅 达成 1 小时沉浸巡航，荣获【平流层漫游机长】称号”*
  - 广播采用平滑淡入淡出，零弹窗、零打扰。
- **🌅 昼夜与天光渐进式演变（Atmospheric Sunlight Progression）**:
  - 随着正向专注时长不断延伸，窗外的平流层天幕与光影可平缓过渡（晨曦 $\to$ 蔚蓝盛夏晴空 $\to$ 金色晚霞 $\to$ 静谧夜航星河），给予用户直观的时光流淌美感。
- **🎫 自由探索航线登机牌结算（Explorer Boarding Pass）**:
  - 降落时，系统根据实际专注时长与总飞行里程生成专属的【自由探索登机牌 / 飞行日志】，记录本次心流轨迹并计入总飞行履历。

## 六、 每日专注时间轴与航班复盘系统（Daily Focus Timeline & Flight Schedule Log）

将用户每日 24 小时内的所有专注飞行轨迹，以“**个人专属航班时刻表与航迹回放**”形式串联，提供沉浸式的复盘体验与时间掌控感。

### 1. 24 小时航线光带（24H Day Ribbon）
- 页面顶部以 00:00 ~ 24:00 为横轴，展示一条代表全天的半透明航迹槽；
- 执飞过的专注时段自动填入对应任务标签的专属色彩块（例如：蓝色=学习、橙色=工作、紫色=阅读）；
- 一眼看清全天的专注时间切片分布与高效黄金时段。

### 2. 垂直航程时刻表卡片流（Vertical Flight Schedule Stream）
按时间先后顺序排列一整天的飞行日志卡片：
- **航班基本信息**: 起降时间跨度（如 `09:30 ~ 10:15`）、专注时长（如 `45m`）、任务标签胶囊；
- **飞行数据与状态**: 执飞航线（`CTU ✈ SHA`）、累积航程（`850 KM`）、专注评级与准点状态；
- **航线转场间隔提示**: 自动计算两次航班之间的地面转场/休息时长（例如：*“航线转场休息 15 分钟 ☕”*），帮助用户建立劳逸结合的健康专注节奏；
- **交互联动**: 点击卡片即可呼出当时生成的【历史精美登机牌与飞行结案报告】。

### 3. 数据持久化与架构规范
- **数据实体**: `DailyTimelineRecord`（包含 `recordId`、`startTime`、`endTime`、`duration`、`tagId`、`originAirport`、`destAirport`、`mileage`、`status` 等）；
- **高性能渲染**: 基于 HarmonyOS ArkTS `LazyForEach` 与 `@ObservedV2` 实现虚拟列表局部刷新，确保长列表秒开与 120fps 满帧滑动；
- **存储方案**: 采用 HarmonyOS `relationalStore` (RDB) 进行本地加密持久化存储，保障数据安全与极速查询。

## 七、 舷窗俯瞰真实卫星地貌系统（Cabin Window Real Earth Satellite Vista）

将真实地球遥感卫星影像（Orthophoto Satellite Map Tiles）投影至机舱舷窗视界底层，实现“**随真实执飞航线实时俯瞰祖国壮美大好河山**”的极致航空沉浸体验。

### 1. 视界分层与多模式融合
舷窗开孔内部采用物理三维多层渲染架构：
```
+-------------------------------------------------------------------------+
| Top Layer: 23 套 3D 摄影级棉花糖云朵（中远近视差流动）                      |
|                                                                         |
| Mid Layer: 真实高空平流层大气瑞利散射蓝光滤镜（Rayleigh Atmospheric Haze）|
|                                                                         |
| Bottom Layer: 真实地球遥感卫星地貌（随航线 GPS 实时推进与透视倾斜）          |
+-------------------------------------------------------------------------+
```

- **🏞️ 晴空地貌俯瞰（Clear-Sky Satellite Vista）**:
  - 当航段处于晴空状态时，窗外呈现真实卫星航拍地表（如飞跃秦岭山脉、黄河弯道、长江三峡、青藏雪山、太湖平原）；
  - 辅以万米高空独有的淡蓝大气散射薄雾，色彩纯净通透，杜绝地图软件的生硬感。
- **☁️ 云隙隐现透视（Cloud-Gap Orthophoto Peeking）**:
  - 卫星地表置于底层，上方自然飘过 3D 积云群；在云团漫游掠过的间隙中，隐约露出下方真实的山川河流脉络，航空临场感极强。
- **🌃 夜航城市灯火（Night Flight City Lights Vista）**:
  - 夜间执飞（20:00 ~ 次日 06:00），底层自动平滑切换为 NASA Black Marble 级别的高清夜间地球卫星灯火图；
  - 俯瞰下方成渝城市群、长三角、京津冀由点点星光汇聚而成的城市夜景。

### 2. 技术实现与性能规范
- **航线坐标实时插值映射（GPS Coordinate Interpolation）**:
  - 根据当前起飞机场、目的机场与专注进度 $t \in [0.0, 1.0]$，实时通过大圆航线（Great-Circle Route）算法计算当前飞机所处经纬度 `(lat, lon)` 与航向角 `heading`；
  - 动态请求对应区域的 Level 7~10 高空巡航级遥感卫星瓦片。
- **透视倾斜投影（Perspective Tilt & Rotation）**:
  - 舷窗并非垂直俯视，而是带有约 $35^\circ \sim 45^\circ$ 的侧向俯视斜角；
  - 对卫星地表施加透视变换矩阵，使近处地貌宽、远处地平线收窄，符合真实飞机舷窗向外望去的透视光学法则。
- **离线与能耗保障（Offline Cache & 120fps Efficiency）**:
  - 针对国内主流精品航线（如京沪、成渝、沪深、成京等），提供高压缩率离线地貌包预缓存机制，在无网络或飞行模式下依然能顺畅俯瞰；
  - 基于 Canvas WebGL / 2D GPU 硬件加速纹理贴图，保证长时间常亮运行温度平稳、满帧极度省电。

## 八、 动态航迹路径回顾与飞行复盘系统（Cinematic Flight Path Replay & Route Review）

支持用户在专注完成或历史复盘时，以专业民航航迹回放（如 Flightradar24 / Relive 3D 轨迹）的电影级动态视效，**一键重温并回放整趟专注航程的飞行路径**。

### 1. 动态航迹回放视觉呈现（Cinematic Playback Experience）
- **🛫 起飞拉升（Takeoff Roll & Climb）**:
  - 地图视角平滑缩放聚焦至起飞机场，飞机沿跑道加速并拉升起飞；
- **✈️ 沿样条曲线动态巡航（Cruise Along Smooth Spline）**:
  - 飞机沿着 Catmull-Rom 样条平滑高速巡航，机尾实时拖曳出**发光渐变彩虹/极光航迹线（Luminous Trajectory Ribbon）**；
- **📍 沿途航路点与里程碑动态弹出（Waypoint Milestones Pop-up）**:
  - 在航迹关键节点（如 15m、30m、45m 或遭遇气流处），地图上自动浮现精致气泡卡片：
    - *“⏱️ 10:15 飞越秦岭 · 进入平流层万米巡航”*
    - *“☁️ 10:30 遭遇微气流 · 保持极高专注度”*
- **🛬 降落定格与登机牌出场（Landing & Boarding Pass Finale）**:
  - 飞机精准对准目的地跑道平稳降落，视角无缝拉升并定格为华丽的【专属航线总结登机牌】。

### 2. 交互控制与社交分享
- **🎮 多倍速播放控制器**:
  - 底部提供悬浮控制器，支持 `暂停/播放`、`进度条滑块拖拽` 与 `1x / 2x / 4x` 倍速切换；
- **🌐 全年/月度航线网络动态织网（Global Route Network Map Replay）**:
  - 在航线图鉴中支持“一键回放本月/今年所有执飞航线在地图上交织成网的壮观动态织网动画”；
- **📸 航迹视频与海报一键导出**:
  - 支持将航迹动态回放导出为精致的高清动图（GIF）、短视频或长图分享海报，极大增强用户的成就感与社交分享欲望。

### 3. 技术实现规范
- **算法基准**: 继承 `smooth-spline-flight-animation` 技能中定义的 Catmull-Rom 样条曲线数学模型与分段弧长参数化（Arc-Length Parameterization），确保匀速丝滑推进；
- **GPU 航迹绘制**: 基于 ArkTS Canvas 2D / WebGL 渲染发光航迹线，配合 Path 渐变与粒子脉冲特效；
- **极速轻量**: 回放动画不依赖额外大体积视频，纯代码几何数学实时演算生成，秒开零等待。
